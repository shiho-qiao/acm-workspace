# 代码模板库

> 全部使用 Rust，稳定版工具链，只用标准库。新模板必须先通过样例验证再收录，并写明用途、复杂度与关联算法。

## 快速输入

- 用途：一次性读入全部输入，按空白切分。
- 复杂度：时间与空间均为输入规模的线性。

```rust
use std::io::{self, Read, Write};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let mut it = input.split_ascii_whitespace();
    let n: usize = it.next().unwrap().parse().unwrap();
    let a: Vec<i64> = (0..n).map(|_| it.next().unwrap().parse().unwrap()).collect();
    let sum: i64 = a.iter().sum();
    let mut out = io::BufWriter::new(io::stdout());
    writeln!(out, "{}", sum).unwrap();
}
```

## 最大公约数

- 用途：求两个非负整数的最大公约数。
- 复杂度：时间 O(log min(a, b))，空间 O(log min(a, b)) 的递归栈。

```rust
pub fn gcd(a: u64, b: u64) -> u64 {
    if b == 0 { a } else { gcd(b, a % b) }
}
```

## 快速幂取模

- 用途：求 base 的 exp 次幂对 modulus 取模；中间用 `u128` 防止溢出。
- 复杂度：时间 O(log exp)，空间 O(1)。

```rust
pub fn mod_pow(mut base: u64, mut exp: u64, modulus: u64) -> u64 {
    let mut result = 1 % modulus;
    base %= modulus;
    while exp > 0 {
        if exp & 1 == 1 {
            result = (result as u128 * base as u128 % modulus as u128) as u64;
        }
        base = (base as u128 * base as u128 % modulus as u128) as u64;
        exp >>= 1;
    }
    result
}
```

## 并查集

- 用途：维护集合合并与连通性查询；带路径压缩与按大小合并。
- 复杂度：单次操作均摊接近 O(1)，空间 O(n)。
- 关联算法：并查集（算法笔记创建后补上链接）

```rust
pub struct Dsu {
    parent: Vec<usize>,
    size: Vec<usize>,
}

impl Dsu {
    pub fn new(n: usize) -> Self {
        Dsu { parent: (0..n).collect(), size: vec![1; n] }
    }

    pub fn find(&mut self, x: usize) -> usize {
        let mut root = x;
        while self.parent[root] != root {
            root = self.parent[root];
        }
        let mut cur = x;
        while self.parent[cur] != root {
            let next = self.parent[cur];
            self.parent[cur] = root;
            cur = next;
        }
        root
    }

    pub fn union(&mut self, a: usize, b: usize) -> bool {
        let (mut a, mut b) = (self.find(a), self.find(b));
        if a == b {
            return false;
        }
        if self.size[a] < self.size[b] {
            std::mem::swap(&mut a, &mut b);
        }
        self.parent[b] = a;
        self.size[a] += self.size[b];
        true
    }
}
```

## 整数溢出安全处理

- 用途：按「结果上界」选择安全位宽；需要显式溢出语义时使用 `wrapping_*`、`checked_*`、`saturating_*`、`overflowing_*`、`Wrapping<T>`。
- 复杂度：全部 O(1)；`i128` 的常数约为 `i64` 的 2~4 倍。
- 关联算法：[[变量、基本类型与整数溢出处理]]
- 验证：rustc 1.92.0 实测，下方注释中的数值即真实打印值。

```rust
use std::num::Wrapping;

/// 乘法取模：中间量可能超 i64 时用 i128 承载。
/// mul_mod(1_000_000_000, 1_000_000_000, 1_000_000_007) == 49
pub fn mul_mod(a: i64, b: i64, m: i64) -> i64 {
    ((a as i128 * b as i128).rem_euclid(m as i128)) as i64
}

/// 非负取模：被除数可能为负时替代 `%`（-21 % 16 == -5，而本函数给 11）。
pub fn mod_pos(x: i64, m: i64) -> i64 {
    x.rem_euclid(m)
}

/// u64 滚动哈希：对 2^64 自然回绕（hash_str("hello") == 30856916622）。
pub fn hash_str(s: &str) -> u64 {
    let mut h = Wrapping(0u64);
    for &c in s.as_bytes() {
        h = h * Wrapping(131) + Wrapping(c as u64);
    }
    h.0
}
```

六件套速查（`i32` 上 `a = b = 10^9` 的实测结果）：

| 写法 | 结果 |
|---|---|
| `a.wrapping_mul(b)` | `-1486618624` |
| `a.checked_mul(b)` | `None` |
| `a.overflowing_mul(b)` | `(-1486618624, true)` |
| `a.saturating_mul(b)` | `2147483647` |
| `(Wrapping(a) * Wrapping(b)).0` | `-1486618624` |
| `a * b`（运行期值，debug 构建） | panic `attempt to multiply with overflow` |
| `a * b`（运行期值，release 构建） | 静默回绕为 `-1486618624` |

## 整数向上取整

- 用途：整数除法向上取整 ⌈n/a⌉，竞赛高频小部件（网格铺设、分块计数）。
- 复杂度：O(1)。
- 关联算法：[[变量、基本类型与整数溢出处理]]；实战例题 [[Codeforces1A-TheatreSquare]]
- 验证：rustc 1.92.0 实测（2026-11-27）。

```rust
// 三种等价写法（实测输出一致）：
// (n + a - 1) / a                预付款式：+（a-1）恰好让任何非零余数过线，且绝不让人过两条线
// n / a + (n % a != 0) as u64    余数判断式（Rust 无三目运算符，用 bool 转整型）
// n.div_ceil(a)                  库函数（仅无符号类型，Rust 1.73+；i64::div_ceil 至今 unstable，实测 E0658）
```

注意：

- 预付款式先估 `n + a - 1` 的上界：CF 1A 约束下最大 1 999 999 999 < i32::MAX（勉强不溢出），更大数据先升宽再减 1。
- **禁用浮点 `.ceil()`**：f64 只有 53 位尾数，实测 `999_999_999_999_999_999u64` 经 f64 来回变成 `1_000_000_000_000_000_000`。
- 乘除混合表达式左结合：`m / a * n / a` 实测等于 `((m/a)*n)/a`（9/3*5/3 = 5 ≠ (9/3)*(5/3) = 3），要分开必须加括号。
