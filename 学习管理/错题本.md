# 错题本

> 每次失败的尝试都记一条，目的是找出根因并写出防再犯检查项。条目同时反向链接到题目笔记。

## 汇总表

| 日期 | 题目 | 错误类型 | 关联算法 | 是否已复盘 |
|---|---|---|---|---|

## 条目模板

```markdown
### {{YYYY-MM-DD}} {{题名}}

- 题目链接：[[{{题目笔记名}}]]
- 错误类型：{{思路 / 实现 / 边界 / 复杂度 / Rust 语言特性}}
- 现象：{{样例不过、答案错误、超时等具体表现}}
- 根因：{{为什么会错，写到能避免再犯的程度}}
- 正确做法：{{}}
- 防再犯检查项：{{提交前要自查的一句话}}
- 关联算法：[[{{算法笔记名}}]]
```
