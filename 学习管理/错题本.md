### 2026-11-26 自查题（6.4 节）

- 题目链接：[[变量、基本类型与整数溢出处理]]
- 错误类型：Rust 语言特性
- 现象：三处 bug 找出 2 处，2 个认知偏差——① 把运行期溢出行为（debug panic / release 回绕）误说成「编译时 panic」；③ 未发现 `a % 16` 对负数输出负余数，且一度把第三处和 `1_000_000_007` 的模运算搅在一起。
- 根因：① 没有区分「编译期能看到值的常量表达式」与「运行期才确定的数值」两条溢出路径；③ 对 Rust `%` 的「余数、符号跟随被除数」语义不熟，看到取模只想到数值大小，没想到符号。
- 正确做法：常量表达式溢出→编译错误；运行期值→debug panic、release 静默回绕。非负取模用 `rem_euclid` 或 `(x % m + m) % m`。
- 防再犯检查项：说溢出后果前先问「这个值编译期可见吗」；写 `%` 前先问「被除数可能为负吗」。
- 关联算法：[[变量、基本类型与整数溢出处理]]
