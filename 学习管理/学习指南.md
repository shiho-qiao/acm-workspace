# ACM 学习指南

> 本清单主来源为 ICPC Curriculum Committee 官方课程大纲（ICPC Foundation 下属），2026-11-27 联网抓取全文核实；NOI 大纲（CCF，2023-03-09 修订版）仅作参考对照，不再是条目来源。语言基础部分按用户约定用 Rust 替代委员会的 C++/Java/Python 教程。
> 条目括号内为委员会大纲原文主题名；标注「NOI/CPH 对照补充」的是委员会大纲未单列、但 ICPC 实战常见的补充专题；「委员会 In Progress」表示该主题在委员会页面处于编写中。
> 勾选规则：条目的进度状态达到 `practiced` 或 `mastered` 时才勾选。「按计划开始学习」（start learning per plan）会选出从上到下第一个未勾选的条目。

## 阶段一：Rust 竞赛语言基础（Course I · Preliminaries）

- [ ] 变量、基本类型与整数溢出处理（`wrapping_*`、`checked_*`）
- [ ] 所有权与借用
- [ ] 输入输出：`std::io` 快速读入
- [ ] 常用集合：`Vec`、`VecDeque`、`HashMap`、`BTreeMap`、`BinaryHeap`
- [ ] 迭代器与排序（`sort_by`、`sort_unstable_by_key`）
- [ ] 复杂度分析（Complexity Analysis）

## 阶段二：Course I · Foundations（基础算法）

- [ ] 枚举与模拟（Bruteforce）
- [ ] 递归与分治（Divide and Conquer，委员会 In Progress）
- [ ] 贪心（Greedy）
- [ ] 排序与离散化（Sorting）
- [ ] 前缀和与差分（Prefix Sum）
- [ ] 位运算（Bits）
- [ ] 二分查找、二分答案与三分（Binary and Ternary Searches、Parametric Search，后者委员会 In Progress）
- [ ] 数学基础：GCD、素数筛、快速幂与抽屉原理（Math、Pigeonhole Principle，后者委员会 In Progress）
- [ ] 高精度运算（`i128`/`u128` 与竖式模拟）——NOI/CPH 对照补充
- [ ] 图基础：DFS、BFS 与拓扑排序（Graphs）
- [ ] 最短路：Dijkstra、Bellman-Ford 与 Floyd（Graphs；Bellman-Ford、Floyd-Warshall 委员会 In Progress）
- [ ] 搜索进阶：剪枝与记忆化搜索——NOI/CPH 对照补充
- [ ] 双向 BFS、迭代加深与启发式搜索——NOI/CPH 对照补充
- [ ] 线性动态规划：LIS 与基础模型（Dynamic Programming、Longest Increasing Subsequence，后者委员会 In Progress）
- [ ] 背包问题（Knapsack，委员会 In Progress）
- [ ] 计算几何基础：向量与基础运算（Geometry）

- [ ] 二分图匹配：Kuhn 算法（Kuhn，委员会 In Progress）
- [ ] 区间动态规划（Dynamic Programming: 2D）
- [ ] 状压动态规划（Dynamic Programming: Bitmask/TSP）
- [ ] 数位动态规划——NOI/CPH 对照补充（委员会 Number Kinds 主题疑似对应，待其课程发布后确认）
