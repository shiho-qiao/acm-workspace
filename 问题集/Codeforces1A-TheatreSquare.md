# Theatre Square（剧院广场铺石板）

- 题面：n×m 广场用 a×a 石板铺满，石板**整块使用、不可切割**、可伸出广场边缘，求最少块数。1 ≤ n, m, a ≤ 10⁹。
- 官方样例：`6 6 4` → `4`
- 关联笔记：[[变量、基本类型与整数溢出处理]]

## 关键思路：网格与乘法原理

横竖各按 a 切条带：`r = ⌈n/a⌉` 个横条 × `c = ⌈m/a⌉` 个竖条 → r×c 个「宽 ≤ a、高 ≤ a」的交叉格，一块石板负责一个交叉格，谁也替不了谁：

$$答案 = \lceil n/a \rceil \times \lceil m/a \rceil$$

- **面积公式 `⌈nm/a²⌉` 是错的**：8×6、a=4 时面积恰好 48 = 3×16 零浪费，但三块 4×4 仍铺不出 8×6（左边缘长 6 不是 4 的倍数，任何贴左边的石板必占恰好 4）。面积是必要条件，不是充分条件。
- 整除情形下界可用面积严格证明（nm/a² 块恰达下界）；一般情形严格证明超纲，竞赛直接背网格公式。

## 解法一：整数网格公式（正解）

- 复杂度：时间 O(1)，空间 O(1)
- 已编译实测：`6 6 4→4`、`8 6 4→4`、`1 1 1→1`、`2 2 3→1`（石板大于广场）、`10⁹ 10⁹ 1→10¹⁸`（u64 上限内）

```rust
use std::io::{self, Read};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let mut nums = input.split_whitespace().map(|num| num.parse::<u64>().unwrap());
    let (m, n, a) = (nums.next().unwrap(), nums.next().unwrap(), nums.next().unwrap());
    println!("{}", theatre_square(m, n, a));
}

fn theatre_square(m: u64, n: u64, a: u64) -> u64 {
    ((m + a - 1) / a) * ((n + a - 1) / a)
}
```

## 解法二：浮点 ceil（反面教材）

`(n as f64 / a as f64).ceil() as u64` —— **f64 只有 53 位尾数**，而 10¹⁸ 需要约 60 位有效数字。实测：`999_999_999_999_999_999u64` 经 f64 来回变成 `1_000_000_000_000_000_000`。大数下 ceil 可能差 1，竞赛整除运算禁用浮点。

## 踩坑记录（本次实战全记录）

1. 把分类讨论展开式（基础块 + 条件补长项）误当统一公式无条件相加 → WA；统一公式是一行乘法，展开式只是它的代数证明。
2. `m / a * n / a` 左结合陷阱：实际是 `((m/a)*n)/a`，反例 `9/3*5/3 = 5 ≠ (9/3)*(5/3) = 3`。
3. 双 ceil 条件项把角块计数两次（多出的横条已含角块）；修正版对拍 30×30×12 零不一致。
4. `(m + a - 1) / 2` 手滑 typo。
5. 变量命名与题面顺序相反（题面 n m a）——本题对称侥幸正确，不对称题会 WA。
6. 交互运行 `read_to_string` 卡住等 EOF：Ctrl+D 结束；OJ 管道自动 EOF，不会卡。

## 复盘

- 独立手算推出「两边都不整除」的展开式 `n/a·m/a + n/a + m/a + 1`，并验算官方样例 ✓
- 卡在「展开式 ≠ 统一公式」约三轮，经反例与对拍后修正
- 方法论收获：极限检验（a=1）两个公式都过，检验点必须选在候选答案分道扬镳处（不整除点）
